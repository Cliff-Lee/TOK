Frequency tables

A frequency table records how often values occur. Continuous data is often grouped into class intervals written as inequalities with no gaps.

Example class intervals: \(0\le x<10\), \(10\le x<20\), \(20\le x<30\). These have no gaps and no overlaps.

Cumulative frequency graph

Cumulative frequency answers “how many values are less than this boundary?” Use the graph to estimate the median, quartiles and percentiles.

CF table and estimates

Graph reading
Median is the 50th percentile. \(Q_1\) is the 25th percentile. \(Q_3\) is the 75th percentile.
Values read from a cumulative frequency graph are estimates, especially for grouped data.

Worked cumulative frequency task

A grouped data set has \(n=80\). Explain how to estimate \(Q_1\), median and \(Q_3\) from the cumulative frequency graph.

\(Q_1\) is at cumulative frequency \(0.25(80)=20\). The median is at cumulative frequency \(0.50(80)=40\). \(Q_3\) is at cumulative frequency \(0.75(80)=60\). Draw horizontal lines from 20, 40 and 60 to the curve, then drop vertical lines to the data axis.

Estimating mean from grouped data

For grouped data, use the midpoint of each interval as a representative value.

\[ \text{estimated mean}=\frac{\sum (\text{midpoint}\times\text{frequency})}{\sum \text{frequency}} \]

Modal class

The modal class is the class interval with the highest frequency. This syllabus point only requires equal class intervals.
The modal class will be highlighted.

Why grouped means are estimates

We do not know exact values

All values in a class are treated as if they were at the midpoint.

Better with narrow intervals

Smaller class widths usually improve the estimate.

Context matters

For skewed data inside a class, the midpoint may not be very representative.

Measures of dispersion

Range

\(\max-\min\). Simple but affected by extremes.

IQR

\(Q_3-Q_1\). Spread of the middle 50%.

Variance

Average squared distance from the mean. Use technology.

Effect of constant changes

Transform the data and observe what changes.

Changing every value by addition shifts the centre but not the spread. Multiplication scales both centre and spread.

Worked examples

Example 1. Estimate the mean from grouped data.

Use each class midpoint. Multiply midpoint by frequency, add these products, then divide by total frequency. The answer is an estimate because exact values inside each interval are unknown.

Example 2. Compare two boxplots.

Compare medians for typical value, IQRs for consistency of the middle 50%, ranges for total spread, and symmetry/skewness using box and whisker lengths. Mention outliers if shown.

Example 3. What happens when all data values are doubled?

The mean and median are doubled. The standard deviation and IQR are also doubled. The variance is multiplied by \(2^2=4\).

Exam checklist

Histogram: equal intervals, touching bars, frequency on vertical axis.
CF graph: plot upper boundaries against cumulative frequency.
Boxplot: label five-number summary and use crosses for outliers.
Comparison: mention median and spread in context.
Grouped mean: use midpoints and state it is an estimate.
Technology: know whether you need \(Sx\) or \(\sigma x\).

Suggested lesson flow

  1. Start with dynamic data sets and ask students to describe shape before calculating.
  2. Build frequency tables and histograms from raw data.
  3. Move from frequency to cumulative frequency and estimate quartiles/percentiles.
  4. Use boxplots to compare two distributions with context language.
  5. Formalise mean, median and mode, then grouped mean estimation.
  6. Use technology for standard deviation and variance, but connect them to visual spread.
  7. Finish with transformation effects and exam-style questions.

Misconceptions to watch

MisconceptionIntervention
Histogram bars can have gaps.Stress continuous grouped data and touching bars.
Cumulative frequency uses class midpoints.Use upper class boundaries for CF graphs.
Boxplot width shows frequency.Box width is usually not frequency in this syllabus.
Mean from grouped data is exact.Call it an estimate and explain midpoints.
Adding a constant changes standard deviation.Use dot plots to show the whole data set shifts without spreading.
