AHL 4.16
Confidence intervals for a normal mean
Visual → theory → TI‑Nspire → exam

Confidence intervals should feel like a picture before they become a formula.

This lab starts with repeated samples and intervals, then slowly builds the ideas of sampling distributions, margin of error, known versus unknown variance, calculator workflow and examination-style responses.

lesson architecture

Use the strengths of the three approaches

Lead visually

Students first see many intervals. Some miss the true mean. The confidence level is about the long-run method, not one magic interval.

Build the theory

Move from sample means to standard error and margin of error: \(\bar x \pm \text{critical value}\times \text{SE}\).

Finish exam-ready

Students choose z or t, operate the TI‑Nspire, state the interval and interpret it in context.

Core misconception to tackle

Weak interpretation: “There is a 95% probability that \(\mu\) is between these two numbers.”

Better examination wording: “Using this method, we are 95% confident that the population mean is between these two numbers.”

In frequentist confidence intervals, the population mean is fixed. The random part is the interval produced from the sample.

The theory being discovered

If \(X\) has population standard deviation \(\sigma\), then the sample mean \(\bar X\) varies less than individual observations:

\[\operatorname{SD}(\bar X)=\frac{\sigma}{\sqrt n}\]

That is why the margin of error contains \(\sqrt n\) in the denominator.

The two formulas

\[\text{Known }\sigma:\quad \bar x \pm z^*\frac{\sigma}{\sqrt n}\]
\[\text{Unknown }\sigma:\quad \bar x \pm t^*_{n-1}\frac{s}{\sqrt n}\]
Key point: the unknown-\(\sigma\) interval uses the sample standard deviation \(s\), so the extra uncertainty is paid for by using the wider \(t\)-distribution.

Why t is wider

When \(\sigma\) is unknown, \(s\) itself changes from sample to sample. The \(t\)-distribution compensates by using a larger critical value, especially when \(n\) is small.

calculator process

TI‑Nspire workflow

Before touching the calculator, write one sentence: “I will use a z-interval because \(\sigma\) is known” or “I will use a t-interval because \(\sigma\) is unknown.”

When raw data is given

1

Open a Lists & Spreadsheet page. Enter the data into a named list, for example lifetimes.

2

Open a Calculator page, then use menu → Statistics → Confidence Intervals.

3

Choose t Interval if \(\sigma\) is unknown, or z Interval if \(\sigma\) is known.

4

Choose Data. Enter the list name, frequency \(=1\), confidence level, and \(\sigma\) if using a z-interval.

When summary statistics are given

1

Use a Calculator page. Go to menu → Statistics → Confidence Intervals.

2

Choose t Interval for \(\bar x, s, n\). Choose z Interval for \(\bar x, \sigma, n\).

3

Choose Stats. Enter \(\bar x\), sample standard deviation \(s\) or population standard deviation \(\sigma\), sample size \(n\), and confidence level.

4

Record the lower and upper bounds. Then write the interpretation in context.

Examination habits

1. Name the interval.
“Since \(\sigma\) is unknown, use a t-interval.”
2. Show key values.
Include \(\bar x\), \(s\) or \(\sigma\), \(n\), confidence level.
3. Interpret in context.
Do not leave the answer as just two numbers.
exit ticket

Can you explain it without a calculator?

1. Complete the sentence

A 95% confidence interval means that if we repeated the sampling process many times, then about _____% of the intervals produced by this method would contain the true population mean.

2. Choose the method

A normal population is sampled. The sample mean is \(43.2\), the sample standard deviation is \(5.1\), and \(n=40\). Should this be a z-interval or t-interval?

3. Explain width

Why is a 99% interval wider than a 90% interval?

4. Correct the misconception

“There is a 95% chance that the true mean is in my interval.” Rewrite this more carefully.

Teacher quick answers

  1. 95.
  2. t-interval, because the population standard deviation \(\sigma\) is unknown and only sample \(s\) is given.
  3. To be more confident, the method must capture the true mean more often, so it uses a larger critical value and a wider interval.
  4. “We are 95% confident that the true population mean lies in this interval.”
