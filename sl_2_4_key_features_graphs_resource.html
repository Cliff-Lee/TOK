SL 2.4 feature vocabulary

Zero/root

Where \(f(x)=0\). On a graph, this is an \(x\)-intercept.

Maximum/minimum

Where the graph reaches a local or global high/low value.

Vertex

The turning point of a parabola or the corner of an absolute value graph.

Asymptote

A line the graph approaches, such as \(x=a\) or \(y=b\).

Intersection

Where two graphs have the same \(x\) and \(y\) values.

Symmetry

A line or point that reflects/rotates the graph onto itself.

Zeros, roots and intercepts

\[ \text{zero/root: } f(x)=0 \] \[ x\text{-intercept: }(x,0) \] \[ y\text{-intercept: }(0,f(0)) \]

Roots and zeros are \(x\)-values. Intercepts are points on the graph.

Example. For \(f(x)=x^2-5x+6\), find the zeros and intercepts.

Factorise: \[ x^2-5x+6=(x-2)(x-3) \] The zeros are \(x=2\) and \(x=3\). The \(x\)-intercepts are \((2,0)\) and \((3,0)\). The \(y\)-intercept is \(f(0)=6\), so \((0,6)\).

Root interpretation

Science

A root might represent when height reaches ground level.

Economics

A root might represent break-even profit \(P(x)=0\).

Geography

An intercept might represent an initial value, such as population at time \(0\).

Warning

Not every mathematical root makes sense in context, especially negative time or negative quantity.

Maximum, minimum, vertex and symmetry

For a quadratic in vertex form \(f(x)=a(x-h)^2+k\), the vertex is \((h,k)\). If \(a>0\), it is a minimum. If \(a<0\), it is a maximum.

a = 1
h = 2
k = -3

Vertex and symmetry
On a GDC, use minimum or maximum tools to find the vertex numerically.

Example. A ball has height \(h(t)=-5(t-2)^2+21\). Interpret the vertex.

The vertex is \((2,21)\). Since the coefficient is negative, this is a maximum. The ball reaches a maximum height of 21 m after 2 seconds.

Vertical and horizontal asymptotes

For \(f(x)=\dfrac{a}{x-h}+k\), the vertical asymptote is \(x=h\), and the horizontal asymptote is \(y=k\).

a = 2
h = 1
k = -2

Asymptote interpretation

Function
Asymptotes
A graph may look like it touches an asymptote on a small screen. Zooming helps reveal the behaviour.

GDC task. Graph \(f(x)=\frac{3}{x-2}+1\). Identify the asymptotes.

The vertical asymptote is \(x=2\), and the horizontal asymptote is \(y=1\). On a GDC, zoom near \(x=2\) and use the table or trace to see the values become very large in magnitude.

Intersections solve equations

Where \(f(x)=g(x)\), the graphs intersect. This is often the easiest way to solve equations with technology.

TI-Nspire CX / CX II instructions

  1. Press Home → New Document → Add Graphs.
  2. Type the function, for example f1(x)=x^2-4x+1, then press Enter.
  3. Change the window if needed: Menu → Window/Zoom → Window Settings. Choose \(x\)-min, \(x\)-max, \(y\)-min and \(y\)-max.
  4. Find a zero/root: Menu → Analyze Graph → Zero. Move to a lower bound, press Enter; move to an upper bound, press Enter.
  5. Find a minimum or maximum: Menu → Analyze Graph → Minimum or Maximum. Select a lower and upper bound around the turning point.
  6. Find an intersection: graph both functions, then Menu → Analyze Graph → Intersection. Select lower and upper bounds around the crossing.
  7. Use Graph Trace to inspect approximate points: Menu → Trace → Graph Trace.
Good exam style: write the function, state the feature requested, give the GDC result to appropriate accuracy, and interpret it in context.

Casio ClassWiz / fx-CG style instructions

  1. Open Graph mode.
  2. Enter the function as \(Y_1\). Enter a second function as \(Y_2\) if finding intersections.
  3. Set a suitable viewing window using V-Window.
  4. Use G-Solve or equivalent tools for Root, Max, Min, \(y\)-intercept and Intersection.
  5. If the feature is not visible, adjust the window and try again.

General GDC strategy

  1. Graph first: check the whole shape and likely number of features.
  2. Window second: adjust zoom so the feature is visible.
  3. Use the correct command: zero, minimum, maximum, intersection, trace/table.
  4. Check reasonableness: a GDC can return a local feature you did not intend.
  5. Interpret: answer in the original context, with units where relevant.

Economics: market equilibrium

Interpretation. The intersection of supply and demand models is the market equilibrium price and quantity.

Science: projectile height

Interpretation. The maximum gives greatest height. The positive root gives when the object hits the ground.

Geography: population model

Interpretation. A horizontal asymptote can model a limiting population or carrying capacity.

International-mindedness: visual vs analytical

Bourbaki-style question: What can be gained from a formal analytical approach?

A formal analytical approach gives precision, generality and proof. It can show why a feature must exist, not just where it appears on one graph.

Mandelbrot-style question: What can be gained from a visual approach?

A visual approach can reveal patterns, structure, irregularity and intuition before formal proof. Graphing technology supports this by making features visible and explorable.

Worked examples

Example 1. Use technology to find the roots and vertex of \(f(x)=x^2-4x+1\).

Graph \(f(x)=x^2-4x+1\). Using a GDC zero/root command gives \[ x\approx0.268,\quad x\approx3.732. \] Using minimum gives the vertex \((2,-3)\). Since the parabola opens upward, this is a minimum value of \(-3\).

Example 2. Find the intersection of \(f(x)=x^2\) and \(g(x)=2x+3\).

Graph both functions and use the intersection command, or solve: \[ x^2=2x+3 \] \[ x^2-2x-3=0=(x-3)(x+1) \] So \(x=3\) or \(x=-1\). The points are \((3,9)\) and \((-1,1)\).

Example 3. Identify the asymptotes of \(f(x)=\frac{2}{x+1}-3\).

The vertical asymptote occurs where the denominator is zero: \[ x+1=0\Rightarrow x=-1. \] The horizontal asymptote is \(y=-3\), because the fraction approaches \(0\) as \(x\) becomes very large or very small.

Suggested lesson flow

  1. Start with slider exploration so students connect parameter changes to graph features.
  2. Use the feature detective tab to build vocabulary and visual recognition.
  3. Separate roots, zeros and intercepts carefully.
  4. Use GDC demonstrations for zeros, min/max and intersections.
  5. Introduce asymptotes visually with zoom and table checks.
  6. Move to contexts: projectile maximum, market equilibrium, population asymptote.
  7. Finish with the question generator and revealable worked solutions.

Misconceptions to watch

MisconceptionIntervention
Root and \(x\)-intercept are identical words.Root is an \(x\)-value; intercept is a coordinate point.
Every maximum/minimum is global.Discuss local vs global features visually.
Asymptote means “line never touched”.Stress “approaches”; some graphs can cross horizontal asymptotes.
GDC answer is automatically meaningful.Always interpret and check the viewing window.
Intersection means crossing only.Intersections can include tangency: same point, same value.
