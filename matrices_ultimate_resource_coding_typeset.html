Why matrices?

A matrix is a compact way to store information in rows and columns. The power comes when we operate on that information all at once.

Teacher move: repeatedly ask, “What do the rows mean? What do the columns mean? What does each entry mean?” This prevents students from treating matrices as meaningless number rectangles.

Matrix structure

A matrix with m rows and n columns has order m × n. The entry aij means: row i, column j.

Common error: students often say columns first. Use the phrase: down then across, or row then column.

Matrix arithmetic

Addition and subtraction only work when matrices have the same order. Scalar multiplication means multiply every entry by the same number.

Equality: turning a matrix statement into equations

If two matrices are equal, their corresponding entries are equal. This lets us solve unknowns entry-by-entry.

Multiplication lab

Matrix multiplication is a machine for combining rows from the first matrix with columns from the second matrix.

If A is m × n and B is n × p, then AB is m × p.
Important: AB and BA are usually different. Sometimes one of them is not even possible.

Diagram: row × column

Why multiplication is defined this way
It matches situations where one table converts one category into another. For example, quantities by brand multiplied by prices by brand gives revenue. In later HL topics, transition matrices convert today’s state into tomorrow’s state.

Non-commutativity explorer

Try two square matrices. Compare AB and BA.

Properties worth knowing

Associative: A(BC) = (AB)C. You may regroup, if the products are defined.
Distributive: A(B + C) = AB + AC. Multiplication distributes over addition.
Not commutative: usually AB ≠ BA. Order matters.
Identity: AI = IA = A, where the identity matrix has 1s on the main diagonal and 0s elsewhere.

Determinant and inverse for 2 × 2

For

A = ab cd
det(A) = ad − bc
A⁻¹ =1/(ad − bc)× d−b −ca
If det(A) = 0, the inverse does not exist. The matrix is singular.

Visual meaning of determinant

For a 2 × 2 matrix, the determinant is the signed area scale factor. If the determinant is zero, the transformation squashes the plane onto a line, so it cannot be reversed.

Systems of equations

Coefficients form A, unknowns form x, constants form b. Solve using x = A⁻¹b.

Eigenvectors

An eigenvector keeps its direction under a matrix transformation. This is the bridge to later HL work on long-term behaviour and phase portraits.

TI-Nspire: entering matrices

1. Press Home → Calculator.
2. Press Menu → Matrix & Vector → Create → Matrix.
3. Choose the number of rows and columns.
4. Type values, moving with arrow keys or Tab.
Tip: Store a matrix as a variable: type the matrix, then press Ctrl + Var or use :=, e.g. a := [[2,1][5,3]].

TI-Nspire: determinant, inverse and solve

Determinant: Menu → Matrix & Vector → Determinant, then enter the matrix.
Inverse: type matrix, then press the power key and enter −1, e.g. a^-1.
System Ax=b: enter a^-1*b, where b is a column matrix.
Check: multiply a*x. It should return b.

Calculator discipline

  • Always write matrix order before multiplying.
  • For 2 × 2 determinants and inverses, practise the by-hand method.
  • For larger matrices, use technology but interpret the result.
  • Do not write b/A. Matrix division is not used. Use A⁻¹b.
  • Order matters: A⁻¹b and bA⁻¹ are not the same expression.
  • If the determinant is zero, say the inverse does not exist.

Exam command words

Mark-winning habits

Extension prompts

  • Why does matrix multiplication feel “unnatural” at first, but become natural in modelling?
  • Can a matrix represent a physical transformation, a data operation and a prediction rule at the same time?
  • What does it mean for a matrix to be reversible? What real-world processes are not reversible?
  • Why does the order of operations matter in matrices, but not in ordinary multiplication?
