The big idea

Inquiry question

How can one small matrix move every point in a shape in a predictable way?

Drag, stretch, rotate and reflect the triangle later. Watch what happens to the two special vectors (1,0) and (0,1).

The unifying model

\[ \text{Linear transformation:}\quad \mathbf{x}'=A\mathbf{x} \] \[ \text{Affine transformation:}\quad \mathbf{x}'=A\mathbf{x}+\mathbf{b} \] \[ A=\begin{pmatrix}a&b\\c&d\end{pmatrix}, \qquad \mathbf{b}=\begin{pmatrix}e\\f\end{pmatrix} \]

A matrix \(A\) handles the linear part: rotation, reflection, stretch, shear, enlargement. The vector \(b\) handles translation.

1Move points

A point \((x,y)\) becomes a new point \((x',y')\).

2Move shapes

A whole triangle is transformed by transforming each vertex.

3Move areas

The determinant tells the area scale factor: image area = \(|det(A)|\) × original area.

1. Discover the matrix from the basis vectors

Try this first

Imagine a transformation sends:

\[ \begin{pmatrix}1\\0\end{pmatrix}\mapsto \begin{pmatrix}a\\c\end{pmatrix}, \qquad \begin{pmatrix}0\\1\end{pmatrix}\mapsto \begin{pmatrix}b\\d\end{pmatrix} \]

What matrix must do this?

Reveal the key idea

The image of \((1,0)\) is the first column of the matrix. The image of \((0,1)\) is the second column.

\[ A=\begin{pmatrix}a&b\\c&d\end{pmatrix} \]

Why this works

Every vector can be built from the basis vectors:

\[ \begin{pmatrix}x\\y\end{pmatrix} = x\begin{pmatrix}1\\0\end{pmatrix} + y\begin{pmatrix}0\\1\end{pmatrix} \]

So once we know where \((1,0)\) and \((0,1)\) go, we know where every \((x,y)\) goes.

3. Transformation types: recognise the structure

Rotations about O

\[ \begin{pmatrix} \cos\theta&-\sin\theta\\ \sin\theta&\cos\theta \end{pmatrix} \]

Area is unchanged because \(det(A)=1\). Orientation is preserved.

Reflections

\[ \text{x-axis: }\begin{pmatrix}1&0\\0&-1\end{pmatrix} \qquad \text{y-axis: }\begin{pmatrix}-1&0\\0&1\end{pmatrix} \] \[ \text{line }y=x:\quad \begin{pmatrix}0&1\\1&0\end{pmatrix} \]

Area is unchanged because \(|det(A)|=1\), but orientation reverses.

Stretches and enlargements

\[ \text{Horizontal stretch factor }k: \begin{pmatrix}k&0\\0&1\end{pmatrix} \] \[ \text{Vertical stretch factor }k: \begin{pmatrix}1&0\\0&k\end{pmatrix} \] \[ \text{Enlargement scale factor }k: \begin{pmatrix}k&0\\0&k\end{pmatrix} \]

The determinant gives the area scale factor.

Exam recognition shortcut

In a \(2 \times 2\) matrix, the columns tell you the images of the basis vectors. This makes many questions faster:

\[ A=\begin{pmatrix}0&-1\\1&0\end{pmatrix} \] \[ \begin{pmatrix}1\\0\end{pmatrix}\mapsto \begin{pmatrix}0\\1\end{pmatrix}, \qquad \begin{pmatrix}0\\1\end{pmatrix}\mapsto \begin{pmatrix}-1\\0\end{pmatrix} \]

So this is a 90° anticlockwise rotation.

4. Composition: order matters

Inquiry

Does a rotation followed by a stretch give the same result as a stretch followed by a rotation?

Use the controls below. The app calculates both \(BA\) and \(AB\).

Key rule

If transformation \(A\) is followed by transformation \(B\), the combined matrix is:

\[ BA \]

The right-hand matrix acts first.

5. Affine transformations: add translation

Linear vs affine

A linear transformation keeps the origin fixed. A translation does not, so translations cannot be represented by a \(2 \times 2\) matrix alone.

\[ \mathbf{x}'=A\mathbf{x}+\mathbf{b} \]

The matrix changes shape, size, orientation or angle. The vector \(b\) moves everything afterwards.

Test it

In the live lab, set \(A\) to the identity and change the translation vector. What happens to the triangle?

Then set \(A\) to a rotation and add a translation. Does it still rotate about the origin?

Useful classroom explanation

Think of an affine transformation as transform, then slide. First the matrix changes the object relative to the origin. Then the vector moves the finished image.

6. Determinant and area scale factor

Area experiment

The original triangle has area calculated from its vertices. The transformed triangle area is compared with \(|det(A)|\).

Why absolute value?

A negative determinant means the orientation has flipped, such as in a reflection. Area cannot be negative, so the area scale factor is \(|det(A)|\).

7. Iterating affine transformations: fractal generator

Inquiry

What happens if we repeatedly apply several shrinking affine transformations to many points?

This is the idea behind simple fractal generation: each point is repeatedly transformed by one of several rules.

Affine rule

\[ \begin{pmatrix}x'\\y'\end{pmatrix} = \begin{pmatrix}a&b\\c&d\end{pmatrix} \begin{pmatrix}x\\y\end{pmatrix} + \begin{pmatrix}e\\f\end{pmatrix} \]

Choose a rule, transform the point, draw it, and repeat thousands of times.

Exam connection

You may be asked to identify or apply repeated affine transformations, especially where matrices create self-similar images. The key is to read each rule as \(x'=Ax+b\).

8. Digital image processing mini-lab

Pixel idea

A digital image can be treated as a set of coordinates. A transformation sends each pixel position to a new position.

Why this matters

Rotating a photo, flipping an image, resizing a graphic, mapping textures in games, and transforming medical scan images all use this coordinate idea.

The mathematics is the same: move every point according to a rule.

Exam method checklist

  1. Write the point as a column vector.
  2. Apply the matrix: \(x'=Ax\).
  3. If affine, add the translation vector: \(x'=Ax+b\).
  4. For a shape, transform every vertex.
  5. For composition, remember: second after first means \(BA\).
  6. For area, use: image area \(= |det(A)| \times\) original area.
  7. If \(det(A)=0\), the image is collapsed onto a line or point.
