Function idea

Each allowed input has exactly one output.

Domain

The set of inputs you are allowed to use.

Range

The set of outputs the function actually produces.

Inverse

A function that undoes the original one, when the original is one-to-one.

What makes it a function?

A relation is a function if each allowed input gives one and only one output.

Allowed

\(x=3\mapsto 7\). One input, one output.

Not a function

\(x=3\mapsto 5\) and \(x=3\mapsto 8\). Same input, two outputs.

Think first

  1. Can every input be used?
  2. Does one input ever produce two outputs?
  3. What pattern connects input to output?

How to think about domain and range

  1. Domain: ask “What \(x\)-values are allowed?”
  2. Range: ask “What \(y\)-values does the function actually produce?”
  3. Use the graph to see where the function exists horizontally and vertically.
  4. Look out for square roots, denominators, and restricted graphs.
For \(f(x)=\sqrt{2-x}\), the expression under the root must be non-negative, so \(2-x\ge 0\). That gives \(x\le 2\). Also square roots are never negative, so the range is \(f(x)\ge 0\).

Formalise the ideas

Function
Each input in the domain has exactly one output.
Domain
The set of permitted inputs.
Range
The set of actual outputs.
Inverse
A function that reverses the original.

Key facts

  1. The graph helps you visualize domain and range.
  2. To find the inverse algebraically, swap \(x\) and \(y\), then solve for \(y\).
  3. The domain of \(f^{-1}\) is the range of \(f\).
  4. The range of \(f^{-1}\) is the domain of \(f\).

Worked examples

Example 1. Let \(f(x)=\sqrt{2-x}\). Find the domain and range.

\[ 2-x\ge 0 \Rightarrow x\le 2 \] so the domain is \(x\le 2\). Also square roots are non-negative, so the range is \(f(x)\ge 0\).

Example 2. If \(f(x)=2x+1\), find \(f^{-1}(x)\).

Let \(y=2x+1\). Swap \(x\) and \(y\): \[ x=2y+1 \] Solve for \(y\): \[ y=\frac{x-1}{2} \] Therefore, \[ f^{-1}(x)=\frac{x-1}{2}. \]

Example 3. If \(f(x)=3x-5\), solve \(f(x)=10\) using the inverse idea.

Solve directly: \[ 3x-5=10 \Rightarrow 3x=15 \Rightarrow x=5 \] Equivalently, \(f^{-1}(10)=5\). The inverse “undoes” the function.

Suggested lesson flow

  1. Start with the function machine to build the basic idea of input and output.
  2. Use the vertical line test to separate “a graph” from “a function graph”.
  3. Move to domain and range, especially square root and reciprocal examples.
  4. Introduce function notation in real models like currency and temperature.
  5. Then build the inverse idea as “undoing”, before showing the reflection in \(y=x\).
  6. Finish with the exam generator and revealable worked solutions.

Misconceptions to watch

MisconceptionIntervention
Confusing domain with range.Use “inputs” vs “outputs” language repeatedly.
Thinking every function has an inverse function.Use \(y=x^2\) on all reals as the counterexample.
Reading \(f^{-1}(x)\) as \(1/f(x)\).Stress the notation: inverse function, not reciprocal.
Ignoring restrictions from roots or denominators.Always ask what makes an input invalid.
