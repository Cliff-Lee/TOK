Combined events
P(A ∪ B) = P(A) + P(B) − P(A ∩ B)

The word or is usually inclusive. Count A, count B, but subtract the overlap because it was counted twice.

Conditional probability
P(A | B) = P(A ∩ B) / P(B)

Once B is known, the denominator is no longer the whole sample space. The new mini-universe is just B.

Independence
P(A ∩ B) = P(A)P(B)

Independent means knowing one event has happened does not change the probability of the other.

Teacher notes: the learning sequence

  1. Start with a sample space grid: every square is one equally likely outcome or one person in a survey.
  2. Group the squares into four regions: A only, B only, both, neither.
  3. Move the same four numbers into a Venn diagram.
  4. Move the same four numbers into a two-way table.
  5. Use the table to build a tree: first split by A, then split each branch by B.
  6. Only after this, write the formulas. They become summaries of the diagrams.
