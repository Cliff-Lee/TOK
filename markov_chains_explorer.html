1. The big idea

A Markov chain models a system that moves between fixed states in discrete steps.

The next state depends only on the current state, not the whole history. This is the memoryless property.
\[\text{current state}\longrightarrow\text{next state}\]

Examples: weather, land quality, bikes in city zones, market share, taxis moving between zones, and population movement.

One convention throughout

This applet uses column state vectors only.

\[s_0=\begin{pmatrix}1\\0\end{pmatrix}\quad\Rightarrow\quad\text{100% starts in state 1}\]
\[s_n=T^ns_0\]

Columns of \(T\) are current states. Rows of \(T\) are next states.

5. Long-term behaviour and steady state

Some chains settle so the state vector changes very little from one step to the next.

\[s_{n+1}\approx s_n\]

At exact steady state:

\[Ts=s\]

So \(s\) is an eigenvector of \(T\) with eigenvalue \(1\), scaled so the entries sum to 1.

8. Quick check

Common mistakes

  • Mixing up “from” and “to”.
  • Forgetting that every column of \(T\) must sum to 1.
  • Using \(s_0T\). Here we use \(Ts_0\).
  • Finding a steady-state vector that does not sum to 1.
  • Not interpreting the result in context.

Teacher notes

Lesson flow

Intuition → diagram → matrix → repeated multiplication → steady state → critique.

Core convention

Only use column vectors: \(s_n=T^ns_0\). Columns of \(T\) sum to 1.

Extension

Use \(Ts=s\), or \((T-I)s=0\), to connect steady state with eigenvalue 1.
