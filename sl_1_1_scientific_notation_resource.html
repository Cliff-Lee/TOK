Operations with numbers in the form \(a\times10^k\), where \(1\leq a<10\) and \(k\) is an integer.
Calculator or computer notation is not acceptable. For example, 5.2E30 should be written as \(5.2\times10^{30}\).

Know

The coefficient \(a\) must be from 1 up to, but not including, 10.

The big idea: a number plus a scale

Scientific notation separates a number into two parts:

\[ \underbrace{a}_{\text{between 1 and 10}} \times \underbrace{10^k}_{\text{scale}} \]

Example: \(6.02\times10^{23}\) means \(6.02\) scaled up by \(10^{23}\).

Memory hook: positive powers make big numbers. Negative powers make small decimals.

Important: \(52\times10^{29}\) is not in scientific form because \(52\) is too large. Write it as \(5.2\times10^{30}\).

Ordinary form → scientific form

  1. Place the decimal after the first non-zero digit.
  2. Count how many places the decimal moved.
  3. If the original number was greater than 10, use a positive power.
  4. If the original number was between 0 and 1, use a negative power.

\(72\,400\,000 = 7.24\times10^7\)

\(0.000\,000\,82 = 8.2\times10^{-7}\)

Scientific form → ordinary form

  1. Start with the coefficient \(a\).
  2. If \(k\) is positive, move the decimal right.
  3. If \(k\) is negative, move the decimal left.
  4. Add zeros as placeholders when needed.

\(4.7\times10^5 = 470\,000\)

\(4.7\times10^{-5}=0.000047\)

Multiplying and dividing

\[ (a\times10^m)(b\times10^n)=ab\times10^{m+n} \] \[ \frac{a\times10^m}{b\times10^n}=\frac{a}{b}\times10^{m-n} \]

After multiplying or dividing, adjust the coefficient so it is between 1 and 10.

\((3\times10^5)(4\times10^7)=12\times10^{12}=1.2\times10^{13}\)

Adding and subtracting

For addition and subtraction, first rewrite the numbers with the same power of 10.

\(4.8\times10^6+3.1\times10^5\)

\(=4.8\times10^6+0.31\times10^6\)

\(=5.11\times10^6\)

Do not add powers: \(10^6+10^5\neq10^{11}\).

Context questions: large numbers

1. The distance from Earth to the Sun is about \(1.496\times10^8\) km. Light travels about \(3.0\times10^5\) km/s. Estimate the time light takes to travel from the Sun to Earth.

\[ \frac{1.496\times10^8}{3.0\times10^5} =0.4987\times10^3 =4.987\times10^2\text{ s} \] This is about \(499\) seconds, or about \(8.3\) minutes.

2. A country has a population of about \(6.8\times10^7\). If each person used \(1.5\times10^2\) litres of water per day, estimate the total daily use.

\[ (6.8\times10^7)(1.5\times10^2)=10.2\times10^9=1.02\times10^{10} \] The total is about \(1.02\times10^{10}\) litres per day.

Context questions: small numbers

3. A red blood cell is about \(7.5\times10^{-6}\) m across. A bacterium is about \(1.0\times10^{-6}\) m across. About how many bacteria lengths fit across one red blood cell?

\[ \frac{7.5\times10^{-6}}{1.0\times10^{-6}} =7.5\times10^0 =7.5 \] About \(7.5\) bacteria lengths.

4. A grain of fine sand has diameter \(2.0\times10^{-4}\) m. A human hair has diameter \(7.0\times10^{-5}\) m. Which is larger, and by what factor?

\[ \frac{2.0\times10^{-4}}{7.0\times10^{-5}} =\frac{2.0}{7.0}\times10^{1} \approx2.86 \] The grain of sand is about \(2.9\) times wider.

TOK / language prompt

Some numbers have names: million, billion, trillion, googol, googolplex. Others are usually written as powers of ten. Discussion: Do names change how real a number feels? Does \(10^{100}\) feel different from “a googol”?

Exam-style practice

Use correct mathematical notation. Avoid calculator notation such as E or EE in final answers.

Mini-checklist before submitting

Coefficient: is \(1\leq a<10\)?
Power: is \(k\) an integer?
Notation: did you write \(\times10^k\), not E notation?
Meaning: does your answer have the right size?

Suggested lesson flow

  1. Start with the scale image and ask: “Which numbers are too annoying to write in ordinary form?”
  2. Introduce \(a\times10^k\) as a compressed way of writing place value.
  3. Use the conversion tab for teacher modelling, then quick whiteboard practice.
  4. Run the ordering game in pairs. Students must justify the order before revealing values.
  5. Move to operations only after students can interpret the size of answers.
  6. Finish with exam-style notation checks: calculator notation is not accepted.
