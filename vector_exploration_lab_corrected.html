Learning route

Core idea

A vector is a quantity with magnitude and direction. The same object can be represented by an arrow, by components, by column notation, or by base vectors.

\[\vec v=\begin{pmatrix}v_1\\v_2\\v_3\end{pmatrix}=v_1\mathbf i+v_2\mathbf j+v_3\mathbf k,\qquad |\vec v|=\sqrt{v_1^2+v_2^2+v_3^2}.\]

Success criteria

You should be able to move between these forms fluently:

\[\vec{AB}=\vec{OB}-\vec{OA}=\vec b-\vec a,\qquad \vec r=\vec a+\lambda\vec d,\qquad \vec r(t)=\vec r_0+t\vec v.\]

And interpret these products:

\[\vec a\cdot\vec b=|\vec a||\vec b|\cos\theta,\qquad |\vec a\times\vec b|=|\vec a||\vec b|\sin\theta.\]

Exam habits checklist

Write the vector equation before solving: \(\vec r=\vec a+\lambda\vec d\).
For an angle, use the direction vectors, not points on the line.
For displacement, subtract in the order \(\text{final}-\text{initial}\).
For speed, take \(|\vec v|\), not the vector itself.
For projectile max height, use the vertical velocity component \(v_y=0\).
For area, use \(|\vec a\times\vec b|\) for a parallelogram and half of that for a triangle.
