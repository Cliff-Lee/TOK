# Vector Treasure Hunt 3D

A static 3D interactive applet for exploring linear combinations of vectors.

## Deploy on Netlify from GitHub

1. Push this whole folder to a GitHub repository.
2. In Netlify, choose **Add new site** then **Import an existing project**.
3. Connect the GitHub repository.
4. Use these build settings:
   - Build command: leave blank
   - Publish directory: `.`
5. Deploy.

All Three.js files are included in `vendor/`, so the live site does not need npm install or a CDN.

If you are adding this to an existing site directory, link directly to:

```text
vector-treasure-hunt-3d.html
```
