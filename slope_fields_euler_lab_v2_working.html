Euler's method stepper

Euler's method uses the current gradient to move one short horizontal step.

xn+1 = xn + h
yn+1 = yn + h f(xn, yn)

Exam-style practice

Quick concept check

Exam hints

For slope fields

Say what the small line segments represent: the gradient dy/dx at each point.

For solution curves

Follow the direction of the segments. Curves from different initial conditions should not cross.

For Euler

Use yn+1=yn+h f(xn,yn). Do not use the new point too early.

For accuracy

Explain step size: smaller h means more recalculations of the gradient.

TI-Nspire instructions

Two reliable approaches are shown below. In exams, values are generated using permitted technology, but method marks often come from showing the formula/table structure.

Spreadsheet method

  1. Open Lists & Spreadsheet.
  2. Column A: n. Enter 0, 1, 2, ...
  3. Column B: x. Put x₀ in B1. In B2 enter =B1+h, then fill down.
  4. Column C: y. Put y₀ in C1.
  5. Column D: m. Enter the gradient formula using B and C, for example =B1+C1.
  6. In C2 enter =C1+h*D1, then fill down.
  7. Read the row where x reaches the target value.

Calculator page recursion

  1. Open Calculator.
  2. Define the function, for example: f(x,y):=x+y.
  3. Store the starting values: x:=0, y:=1, h:=0.2.
  4. Repeat: m:=f(x,y), then y:=y+h*m, then x:=x+h.
  5. Write down each row if the question asks for working.
Important: update y using the old value of x and y. A common calculator mistake is updating x first and then using the new x in the old gradient.

Teacher notes: lesson sequence

1. Inquiry

Students click points and predict whether the curve rises, falls, or levels out.

2. Structure

Connect the table of gradients to the short tangent segments.

3. Curves

Draw solution curves through initial conditions. Emphasise no crossing and tangent following.

4. Euler

Introduce “old y plus step times gradient”. Build the table slowly.

5. Technology

Use TI-Nspire/spreadsheet once students understand the columns.

6. Exam readiness

Practise formula, table, final estimate, and an interpretation sentence.

Misconceptions

  • Thinking the slope field is one solution rather than a family.
  • Using xn+1,yn+1 to calculate the old gradient.
  • Forgetting negative step sizes are possible when moving backwards.
  • Drawing curves that cut across the tangent segments.
