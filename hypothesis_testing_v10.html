What is a hypothesis test?

A hypothesis test asks:

If H₀ were true, would this sample result be surprisingly extreme?

It does not prove that a claim is true. It measures how unusual the evidence is under a model.

Core logic: assume H₀ → calculate evidence → find p-value or critical region → compare with α → conclude in context.

SL coreHL / AHL

χ² goodness-of-fit SL

Data: one categorical variable.

H₀: data follows the stated distribution. H₁: data does not follow the stated distribution.

χ² = Σ (O − E)² / E, df = categories − 1

Numerical example: fair die

A die is rolled 120 times. Observed counts are 18, 22, 17, 19, 20, 24. If the die is fair, each expected count is 20.

χ² = (18−20)²/20 + (22−20)²/20 + ... + (24−20)²/20
χ² = (4+4+9+1+0+16)/20 = 1.70
df = 6 − 1 = 5, so p ≈ 0.889
Decision: p > 0.05, so do not reject H₀. There is not enough evidence that the die is unfair.

χ² independence SL

Data: two categorical variables in a contingency table.

H₀: variables are independent. H₁: variables are not independent.

Expected = row total × column total ÷ grand total

Numerical example: lunch choice × year group

Year 1028191360

Expected Year 10, A = 60×42÷120 = 21
Expected row values: 21, 21.5, 17.5 and 21, 21.5, 17.5
χ² = Σ(O−E)²/E ≈ 7.56, df = (2−1)(3−1) = 2
p ≈ 0.0228
Decision: p < 0.05, so reject H₀. There is evidence that lunch choice is related to year group.

Pooled two-sample t-test SL

Data: two independent numerical samples.

H₀: μ₁ = μ₂. H₁: μ₁ ≠ μ₂, μ₁ > μ₂, or μ₁ < μ₂.

SL note: population variances are unknown but assumed equal, so use pooled = yes.

Numerical example: two classes

Class A: n₁=14, x̄₁=72.4, s₁=8.1. Class B: n₂=16, x̄₂=66.8, s₂=7.4. Test whether the means are different.

sₚ = √(((13)(8.1²)+(15)(7.4²))/(14+16−2)) ≈ 7.733
t = (72.4−66.8)/(7.733√(1/14+1/16)) ≈ 1.979
df = 28, two-tailed p ≈ 0.0577
Decision: p > 0.05, so do not reject H₀. The evidence is not quite strong enough at 5%.

One-sample t-test HL

Data: one numerical sample, population variance unknown.

H₀: μ = μ₀. H₁: μ ≠ μ₀, μ > μ₀, or μ < μ₀.

Numerical example: battery claim

A company claims μ=10 hours. A sample of 8 batteries gives mean x̄=9.75 and standard deviation s=0.245. Test whether the mean is less than 10.

H₀: μ = 10, H₁: μ < 10
t = (9.75−10)/(0.245/√8) ≈ −2.887
df = 7, left-tailed p ≈ 0.0117
Decision: p < 0.05, so reject H₀. There is evidence that the mean battery life is less than 10 hours.

z-test for a mean HL

Data: one numerical sample, population variance known.

H₀: μ = μ₀. Use this only when σ is known.

Numerical example: filling machine

A machine should fill bottles with μ=500 ml. From n=36 bottles, x̄=501.8 ml. The population standard deviation is known: σ=6 ml. Test whether the mean is different from 500.

H₀: μ = 500, H₁: μ ≠ 500
z = (501.8−500)/(6/√36) = 1.80
two-tailed p ≈ 0.0719
Decision: p > 0.05, so do not reject H₀. There is not enough evidence that the mean fill has changed.

Paired t-test HL

Data: before/after or matched pairs.

Method: create differences d, then run a one-sample t-test on d.

Numerical example: before and after revision

Six students improve by d = after − before: 5, −1, 4, 2, 1, 3 marks. Test whether the mean improvement is greater than 0.

H₀: μd = 0, H₁: μd > 0
d̄ = 2.333, sd ≈ 2.160
t = 2.333/(2.160/√6) ≈ 2.646
df = 5, right-tailed p ≈ 0.0228
Decision: p < 0.05, so reject H₀. There is evidence of an improvement after revision.

Binomial test HL

Data: fixed independent success/failure trials.

H₀: p = p₀. Under H₀, X follows B(n, p₀).

Numerical example: penalty saves

A goalkeeper usually saves 30% of penalties. In 20 penalties, they save 10. Test whether the save rate is greater than 30%.

H₀: p = 0.30, H₁: p > 0.30
X ~ B(20, 0.30) under H₀
p-value = P(X ≥ 10) ≈ 0.0480
Decision: p < 0.05, so reject H₀. There is evidence that the save rate is greater than 30%.

Poisson test HL

Data: counts in fixed time, area or space.

H₀: λ = λ₀. Under H₀, X follows Poisson(λ₀).

Numerical example: cars per minute

A road usually has a mean of 8 cars per minute. In one minute, 14 cars are counted. Test whether the rate has increased.

H₀: λ = 8, H₁: λ > 8
X ~ Poisson(8) under H₀
p-value = P(X ≥ 14) ≈ 0.0342
Decision: p < 0.05, so reject H₀. There is evidence that the car rate has increased.

Correlation test HL

Data: two numerical variables or ranked variables.

H₀: ρ = 0. H₁: ρ ≠ 0, ρ > 0, or ρ < 0.

Numerical example: height and arm span

For n=10 students, technology gives a sample correlation r=0.64. Test whether there is a positive linear relationship.

H₀: ρ = 0, H₁: ρ > 0
t = r√((n−2)/(1−r²)) = 0.64√(8/(1−0.64²)) ≈ 2.356
df = 8, right-tailed p ≈ 0.0231
Decision: p < 0.05, so reject H₀. There is evidence of a positive linear relationship. This does not prove causation.

Critical value method Exam skill

Instead of comparing p with α, compare the test statistic with a critical value or critical region.

Numerical example: same z-test, critical values

For a two-tailed z-test at the 5% level, the critical values are −1.96 and 1.96. Suppose the observed test statistic is z=1.80.

Rejection region: z < −1.96 or z > 1.96
Observed z = 1.80, which is not in the rejection region
Decision: do not reject H₀. This matches the p-value method because p≈0.0719 > 0.05.

Type I error, Type II error and power HL / AHL

This page is about what your decision means in the real world. A hypothesis test makes a decision from sample evidence, but the real situation could be different.

Student task: read the conclusion, then ask: What did we decide? and what is actually true? That tells you whether it is Type I, Type II, power, or a correct non-rejection.

The four possible outcomes

Think of this as a decision table. The rows are what you did in the test. The columns are the real truth, which we usually do not know.

Test decisionH₀ is actually trueH₁ is actually true
Reject H₀Type I error
False alarm		Correct detection
This is counted by power.
Do not reject H₀Correct non-rejection
No false alarm.		Type II error
Missed detection.

One story to remember it

School example: A teacher tests whether a new revision method improves scores.

H₀: the new method does not improve mean scores.

H₁: the new method does improve mean scores.

  • Type I: we say the method works, but actually it does not.
  • Type II: the method really works, but our sample does not give enough evidence.
  • Power: the method really works and our test successfully detects it.

Type I error

Meaning: reject H₀ when H₀ is actually true.

Probability: α.

α = P(reject H₀ | H₀ true)

Numerical example: If α = 0.05, then when H₀ is really true, about 5% of repeated tests would wrongly reject it.

Memory cue: false alarm.

Type II error

Meaning: do not reject H₀ when H₁ is actually true.

Probability: β.

β = P(do not reject H₀ | H₁ true)

Numerical example: If β = 0.20, then when there really is an effect, about 20% of repeated tests would fail to detect it.

Memory cue: missed detection.

Power

Meaning: correctly reject H₀ when H₁ is actually true.

Formula: power = 1 − β.

power = P(reject H₀ | H₁ true)

Numerical example: If β = 0.20, then power = 0.80. The test has an 80% chance of detecting the effect if the effect is really there.

Worked examples

Example 1: fire alarm analogy

H₀There is no fire.
Reject H₀The alarm says there is a fire.
Type I errorThe alarm rings, but there is no fire. This is a false alarm.
Type II errorThere is a fire, but the alarm does not ring. This is a missed detection.
PowerThere is a fire, and the alarm rings.

Example 2: medical test

H₀The patient does not have the disease.
H₁The patient has the disease.
Type I errorThe test says positive, but the patient is actually healthy.
Type II errorThe test says not enough evidence, but the patient actually has the disease.
PowerThe patient has the disease and the test detects it.

Example 3: power means “catching a real effect”

Story: suppose a new revision method really does improve scores. So H₁ is actually true.

The test can now do one of two things:

Test rejects H₀Good result. It detected the real improvement. This is power.
Test does not reject H₀Bad result. It missed the real improvement. This is a Type II error.

So, when H₁ is really true:

power + β = 1    so    power = 1 − β

This slider only shows the formula power = 1 − β. In a real test, students do not simply choose β after seeing the data. The next section shows the trade-off with α.

How can power increase?

Power increases when the real effect is easier to see. Use this as the main idea.

ChangeWhy it helpsStudent example
Larger sample sizeRandom luck averages out.80 students gives clearer evidence than 8 students.
Larger real effectA big difference is easier to detect.A 12-mark improvement is easier to spot than a 1-mark improvement.
Less variationThe data are less noisy.If students have similar starting scores, the pattern is clearer.
Larger αThe rejection region becomes easier to enter.At 10% you reject more easily than at 5%.
One-tailed testAll the rejection area is put on one side.Use only if “increase” or “decrease” was predicted before seeing the data.
Important trade-off: increasing α can increase power, but it also increases the chance of a Type I error. More power is good, but not every method is free.
Memory sentence: Power is high when a real effect is unlikely to be missed.

Why not just make β very small?

Because β is not normally the knob you turn. In school-level hypothesis testing, you choose the significance level α first. That sets how easy it is to reject H₀. Once α, sample size, variation and the real effect size are fixed, β is then determined.

Main trade-off: If you make the test reject H₀ more easily, β goes down and power goes up, but α goes up too. So you detect more real effects, but you also create more false alarms.

Interactive trade-off model

This simplified model uses a right-tailed z-test. H₀ is centred at 0. H₁ is shifted to the right. The vertical line is the rejection boundary.

Signal strength represents how easy the real effect is to see. A bigger sample, larger real effect, or less variation makes this number bigger.

The bad way to get more power

ChangeIncrease α from 5% to 10%.
EffectThe rejection region gets larger, so β usually decreases and power increases.
CostYou now allow about 10 false alarms in every 100 cases where H₀ is actually true, instead of about 5.

The better way to get more power

Bigger sampleMakes the real effect easier to see without simply relaxing the standard of evidence.
Less noisy dataMeasurements are more consistent, so the signal stands out.
Stronger real effectA large improvement is easier to detect than a tiny improvement.

Final checklist

Before calculating

  • Identify data type.
  • Identify parameter or relationship.
  • Write H₀ and H₁.
  • Choose one-tailed or two-tailed.
  • Check assumptions, especially expected frequencies for χ².

After calculating

  • Compare p with α, or statistic with critical value.
  • Reject or do not reject H₀.
  • Never write “accept H₀”.
  • Answer in context.
  • Mention significance level.
Conclusion templates:
Since p < α, reject H₀. There is sufficient evidence at the 5% significance level to suggest that ...

Since p > α, do not reject H₀. There is insufficient evidence at the 5% significance level to suggest that ...
