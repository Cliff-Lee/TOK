“Sketch” means show the structure

A sketch should show the correct shape and labelled key features. It does not have to be perfectly to scale.

Mini task. Sketch \(y=(x-2)^2-3\). What must be labelled?

Label the axes, equation, vertex \((2,-3)\), \(y\)-intercept \(1\), and \(x\)-intercepts \(x=2\pm\sqrt3\). Show an upward-opening parabola.

“Draw” means more accurate

A draw command usually expects greater accuracy: plotted points, a scale, and a graph that is close to the real one.

Step-by-step TI-Nspire instructions

  1. Press Home → New Document → Add Graphs.
  2. In the entry line, type a function such as f1(x)=x^2-4x+1, then press Enter.
  3. Set a useful viewing window: Menu → Window/Zoom → Window Settings. Enter \(x\)-min, \(x\)-max, \(y\)-min, \(y\)-max.
  4. Trace values: Menu → Trace → Graph Trace.
  5. Find a zero: Menu → Analyze Graph → Zero. Set a lower and upper bound around the crossing.
  6. Find a minimum or maximum: Menu → Analyze Graph → Minimum or Maximum. Set bounds around the turning point.
  7. Find an intersection: enter both functions, then use Menu → Analyze Graph → Intersection.

Explore sums and differences

The sum or difference graph is made by adding or subtracting the \(y\)-values at the same \(x\)-value.

Worked technology example

Graph \(f(x)=x^2-3\), \(g(x)=2x+1\), and \(h(x)=f(x)-g(x)\). Find the \(x\)-intercepts of \(h\).

\[ h(x)=(x^2-3)-(2x+1)=x^2-2x-4. \] The zeros solve \(x^2-2x-4=0\), so \[ x=\frac{2\pm\sqrt{20}}{2}=1\pm\sqrt5. \] Thus \(x\approx -1.236\) and \(x\approx 3.236\). On TI-Nspire, graph \(h\), then use Menu → Analyze Graph → Zero around each crossing.

Formal sketching method

  1. Identify the type of function or relationship.
  2. Choose a sensible viewing window or axis scale.
  3. Find and label \(f(0)\), the \(y\)-intercept.
  4. Solve \(f(x)=0\) for \(x\)-intercepts where possible.
  5. Find turning points, endpoints, asymptotes, and intersections.
  6. Draw the correct shape through the features.
A graph is not decoration. It is another representation of the function.

Worked examples

Example 1. Sketch \(y=x^2-4x+3\).

\[ y=x^2-4x+3=(x-1)(x-3) \] so the \(x\)-intercepts are \((1,0)\) and \((3,0)\). The \(y\)-intercept is \((0,3)\). Also \[ y=(x-2)^2-1 \] so the vertex is \((2,-1)\). Sketch an upward-opening parabola through these points.

Example 2. Sketch \(y=\frac{1}{x-2}+1\).

The vertical asymptote is \(x=2\). The horizontal asymptote is \(y=1\). The \(y\)-intercept is \(1/2\). The \(x\)-intercept is \(x=1\). Sketch two reciprocal branches approaching the asymptotes.

Exam sketch checklist

Axes: labelled with clear scale.
Equation: identify which graph is which.
Features: intercepts, turning points, asymptotes, endpoints.
Shape: correct curvature and direction.
Technology: use it to find features, not to avoid explanation.
Context: interpret in real-world language.

Suggested lesson flow

  1. Start with the graph explorer and ask students to describe what changes.
  2. Make the distinction between “sketch” and “draw” explicit.
  3. Use key-feature detective tasks to train graph annotation.
  4. Demonstrate TI-Nspire graphing, zero, minimum, maximum, and intersection tools.
  5. Move to sums and differences using technology.
  6. Finish with context-to-sketch and exam-generator tasks.
