The key idea

A second-order equation tracks position and velocity at the same time.

\[x''=F(t,x,x')\]

Let \(v=x'\). Then

\[x'=v,\qquad v'=F(t,x,v)\]

Euler’s method updates both variables using their current rates of change.

1. Big picture: why rewrite the equation?

A second-order differential equation involves acceleration. Euler’s method needs first-order rates of change. So we split the motion into two connected variables:

Second-order form

One equation involving position, velocity and acceleration.

\[x''=F(t,x,x')\]

→

Introduce velocity

Let \(v=x'\), so acceleration is \(v'\).

\[x'=v\]

→

Coupled system

Two first-order equations run together.

\[x'=v,\quad v'=F(t,x,v)\]

Position graph

Shows \(x\) against \(t\). Useful for estimating values such as \(x(2)\).

Velocity graph

Shows how fast and in what direction the object or quantity is changing.

Phase portrait

Shows \(v\) against \(x\). This reveals spirals, cycles, damping and instability.

4. Phase portrait: see the system moving

The phase plane plots \(x\) horizontally and \(v=x'\) vertically. Each arrow says: “from this state, where does the system move next?”

direction fieldEuler pathcurrent point

How to read it

Each point is a state.
\((x,v)\) means “position is \(x\), velocity is \(v\)”.
Horizontal motion comes from \(x'=v\).
If \(v>0\), move right. If \(v<0\), move left.
Vertical motion comes from \(v'=F(t,x,v)\).
If acceleration is positive, the velocity increases.
Spirals often mean oscillation.
Inward spiral: damping. Outward spiral: instability. Closed loop: repeating cycle.
For systems where \(F\) explicitly contains \(t\), the phase arrows can change over time. The plot uses the current animation time.

5. Step-size experiment: why \(h\) matters

Euler’s method follows the tangent direction for one whole step. A large step may drift away from the true curve, especially when the curve bends quickly.

Compare several step sizes

small \(h\)medium \(h\)large \(h\)reference, where available

What students should notice

Euler uses the current slope as if it remains constant over the whole interval. But in curved motion, the slope changes during the interval. If \(h\) is too large, the approximation repeatedly steps in slightly wrong directions, and the errors accumulate.

A smaller step size usually gives a better approximation but requires more calculations. Euler’s method is less accurate where the solution changes gradient rapidly or oscillates quickly.

A numerical method is stable if small calculation errors do not grow uncontrollably. Euler’s method can become unstable for some step sizes even when the real system is stable.

6. Exam method: what to write

Standard method

Define velocity.
Let \(v=\dfrac{dx}{dt}\).
Rewrite acceleration.
Since \(v=x'\), then \(v'=x''\).
Build the system.
\(x'=v\), and \(v'=F(t,x,v)\).
Write Euler recurrences.
\(x_{n+1}=x_n+hv_n\), \(v_{n+1}=v_n+hF(t_n,x_n,v_n)\).
Substitute initial values.
Use the given \(t_0\), \(x_0\), and \(v_0\).
Comment on accuracy.
Smaller \(h\) gives more reliable results, but more steps are needed.

Worked non-exact example

A pendulum with damping is modelled by

\[\theta''+0.3\theta'+\sin(\theta)=0,\quad \theta(0)=1.2,\quad \theta'(0)=0.\]

Let \(v=\theta'\). Then

\[\theta'=v,\qquad v'=-0.3v-\sin(\theta).\]

With step size \(h=0.1\):

\[\theta_{n+1}=\theta_n+0.1v_n\]

\[v_{n+1}=v_n+0.1(-0.3v_n-\sin(\theta_n)).\]

This is a good example for Euler because \(\sin(\theta)\) makes the equation non-linear, so the simple matrix/eigenvalue exact method is not the main tool.
