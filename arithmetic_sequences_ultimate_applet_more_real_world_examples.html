IB DP AI SL 1.2 • Arithmetic sequences and series

From patterns to formulas to models.

This lab starts visually, connects arithmetic sequences to linear functions, builds the sum formula, practises sigma notation, applies simple interest, and finishes with imperfect real-life arithmetic models.

Core ideas
Arithmetic means constant difference: \(u_{n+1}-u_n=d\)
Nth term: \(u_n=u_1+(n-1)d\)
Series: \(S_n=\frac n2(2u_1+(n-1)d)=\frac n2(u_1+u_n)\)
Sigma: \(\sum_{r=p}^{q} f(r)\) has \(q-p+1\) terms

1. Explore an arithmetic sequence

Change the first term, common difference, and number of terms. Watch the table and graph update. The graph is a line because each step in \(n\) adds the same amount.

Table and graph

2. Build the nth-term formula

The key move is to count how many jumps from the first term to the nth term. To reach \(u_n\), you make \(n-1\) jumps.

Why \(n-1\)?

Function link: an arithmetic sequence is a linear function restricted to integer inputs: \(u(n)=u_1+d(n-1)\). The common difference is the gradient.

3. Recover the hidden sequence

Given two terms, solve for \(d\) first by comparing how many jumps separate them, then work back to \(u_1\).

Structure

Suppose you know \(u_a\) and \(u_b\).

Number of jumps: \(b-a\)

Change in value: \(u_b-u_a\)

So \(d=\dfrac{u_b-u_a}{b-a}\)

Then \(u_1=u_a-(a-1)d\)

4. Add the sequence: arithmetic series

Pair the first and last terms. Each pair has the same total. This is the Gauss idea behind the sum formula.

Pairing visual

5. Prove the sum formula

Start with a famous number trick, then generalise the same pairing idea to any arithmetic sequence.

Warm-up: add the integers from 1 to 100

A well-known story says that the young Carl Friedrich Gauss was asked to add \(1+2+\cdots+100\). Instead of adding one by one, he paired the first and last terms.

6. Sigma notation without miscounting

Use a linear expression inside sigma. The terms form an arithmetic sequence. The dangerous part is the number of terms: from \(r=p\) to \(r=q\) there are \(q-p+1\) terms, not always \(q\).

7. Simple interest as an arithmetic model

Simple interest adds the same amount each year, so the account balance is arithmetic/linear: \(A=P(1+rt)\).

Compound interest is not arithmetic because the difference between years changes. It is shown only as an extension/comparison.

Teacher route through the applet

Recommended lesson sequence
  1. Explore: start with a salary pattern or growing pattern. Students describe the rule in words before formulas.
  2. Formula: build \(u_n=u_1+(n-1)d\) by counting jumps.
  3. Missing terms: use two known terms to solve for \(d\), then \(u_1\).
  4. Series: use pairing to derive \(S_n\), not just memorise it.
  5. Proof tab: start with the 1–100 number trick, then generalise by writing the sum forwards and backwards.
  6. Sigma: practise expanding and counting terms, especially when the lower limit is not 1.
  7. Interest/model: apply to finance and imperfect real data.
  8. Practice: mixed questions for retrieval and exam readiness.
Assessment objectives covered

Recognising arithmetic sequences, using nth-term and sum formulas, interpreting sigma notation, solving for unknown parameters, using technology-style tables/graphs, applying simple interest, and judging whether a real model is approximately arithmetic.

Common misconceptions to target
  • Using \(nd\) instead of \((n-1)d\).
  • Thinking the upper sigma limit is always the number of terms.
  • Confusing a sequence term \(u_n\) with a series sum \(S_n\).
  • Using compound interest for a simple-interest question.
  • Assuming all real data must have exactly equal differences.

Design notes

Pedagogical synthesis: inquiry first, then linear-function connection, then algebraic fluency, then exam-style sums/sigma, then real modelling.

Inquiry-first
